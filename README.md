### 🚀 About This Portfolio

This portfolio serves as a demonstration of my skills as a Senior Software Engineer by showcasing well-structured, high-quality code and best practices in modern web development. The project is built with TypeScript, React, Vite, Jest, and Playwright, ensuring a robust, efficient, and scalable architecture.

The key objectives of this portfolio are:

✅ Showcase My Technical Expertise – Demonstrate my ability to build performant, maintainable applications using modern front-end technologies.

✅ Highlight Best Practices – Use clean architecture, modular code, testing strategies, and performance optimizations.

✅ Demonstrate Testing Standards – Ensure high reliability through comprehensive unit testing (Jest, React Testing Library) and E2E testing (Playwright).

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🛠️ Tech Stack

- **Framework:** React 18 with TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Testing:** Playwright (E2E), React Testing Library (Unit)
- **Internationalization:** i18next
- **State Management:** React Hooks
